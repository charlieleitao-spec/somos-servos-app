# Biblioteca Servita: fonte comum

O catálogo local é gerado a partir de `liturgia-osm/www/data/biblioteca-servita-catalogo.json`. Não edite seus títulos, edições ou páginas separadamente neste projeto.

`conteudo-servita.lock.json` registra a revisão aprovada e os hashes da fonte. O workflow de validação confere as cópias e interrompe a integração se houver divergência.

Para atualizar, siga o [procedimento na fonte](https://github.com/charlieleitao-spec/liturgia-osm/blob/2016f2d828c3d46b2c50455414dd016f12411b74/docs/conteudo-compartilhado.md). Use um checkout limpo da revisão escolhida e execute o sincronizador com o perfil `somos`; revise e integre os arquivos gerados.

O leitor não consulta o GitHub durante o uso. Os PDFs incluídos no aplicativo e suas cópias offline permanecem preservados. A página Recursos e os artigos próprios do Blogger mantêm seus respectivos papéis; não foi criada publicação automática.
