# Biblioteca e Formação Servita — preparação para o Blogger

Esta proposta não altera o aplicativo nem publica conteúdo no Blogger.

## Como utilizar

1. No Blogger, criar uma página com o título **Biblioteca e Formação Servita**.
2. No editor em modo HTML, inserir o conteúdo de `biblioteca-formacao-servita.html`.
3. Conferir no navegador e no celular os cinco destinos permanentes.
4. Após publicar a página, adicionar ao menu **Documentos e História** o endereço definitivo atribuído pelo Blogger.
5. Manter **Escola de Mariologia** também no menu **Maria**, sem duplicar a série.

Não presumir a URL da nova página antes de ela existir. Não modificar os workflows de publicação nem o APK por causa desta página.
