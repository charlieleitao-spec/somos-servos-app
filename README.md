# Somos Servos App

Aplicativo web instalável do blog [Somos Servos da Virgem Gloriosa](https://somosservos.blogspot.com/).

## Publicar no GitHub Pages

1. Crie o repositório público `somos-servos-app`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main**, pasta **/(root)**, e salve.
6. Aguarde a publicação em `https://charlieleitao-spec.github.io/somos-servos-app/`.

Depois, abra o endereço no Chrome e toque em **Instalar**.
